    第十三讲 · 全课程收束：从一次战役看研究纪律的完整拼图¶

    第五章 · 方法沉淀（第二讲，全课程终讲） 学习目标：把十二讲的概念拼成一张完整的作战地图；沉淀可直接带走的研究纪律清单。

    1. 全课程的叙事主线回顾¶

    一门课讲了十三个故事，其实只有一条线：当 AI 把"产生假设"的成本降到接近零，研究体系的价值重心整体迁移到了假设产生之后。

    第一章  工厂很能干        290 个因子一晚上，代码质量过硬，假设质量平平
第二章  但成绩单不可信    多重检验 + 风格 beta + 净费 + ——独立验证零存活
第三章  连地基都要审      双重复权 + 基准伪影 + 五坑——数据与量定义的审计
第四章  幸存者依然谦卑    +2.37%/yr，现金管理级，判决只是获得认真对待的资格
第五章  瓶颈回到选择      排除清单 + 正交四问 + 经济门槛——便宜的否决保护昂贵的投入

    数字版主线（值得背下来）：

    自报最高 +26.5% → 独立验证 0 存活；假的 carry +18%（复权 bug）→ 真的 carry +2.37%； REJECTED −0.49% / INCONCLUSIVE +1.00%（p=0.062）/ SUPPORTED +2.37%。 真 alpha 又小又难看；假 alpha 又大又合理。

    2. 一张作战地图：全体系的组件与接口¶

    ┌─ 机会筛选 ──────────────────────────────────────────────┐
│  排除清单(DO NOT RESEARCH / YET) → 正交四问 → 经济门槛    │
│         ↓ 通过                                          │
├─ 工厂层（AI）───────────────────────────────────────────┤
│  数据面板(人定) → 五步循环 → 候选假设流                   │
│         ↓ 产出单位=候选假设,不是可上线因子                 │
├─ 验证层（制度）─────────────────────────────────────────┤
│  独立数据复算 → 预注册门槛(DSR/主副裁判/分年/正交化)       │
│  → OOS 一次性判定 → 三种判决(S/R/I) → 假设族封禁          │
│         ↓ SUPPORTED                                     │
├─ 地基审计（贯穿）───────────────────────────────────────┤
│  五层审计栈: 量的定义→数据地基→可实现性→收益来源→统计充分  │
│  口径审计六步: 症状→根因→影响面→裁定→处置→下游             │
│         ↓                                               │
├─ 部署层 ───────────────────────────────────────────────┤
│  影子模式30天(链路验证) → 部署决策 → 监控预注册(衰减+变体禁令)│
│         ↓ 全程                                          │
└─ 记忆层 ───────────────────────────────────────────────┐
   研究账本: 裁决留档/负结果入账/勘误编号/历史可复算          │

    每个组件单独都不新——预注册是临床试验几十年的标准，多重检验校正是学术统计的常识，影子模式是软件工程的金丝雀发布。这套体系的新意只在严肃程度的一致性：当假设生产被 AI 加速百倍，这些旧制度的执行强度必须同步升级，否则它们就从"防线"退化成"装饰"。

    3. 十条带走的研究纪律¶

    全课程压缩成十条，每条注明出处讲次：

    1. 排行榜先看评估次数列，再看收益列——combos/versions 是运气成分的上限（E2）
    2. 对每个结果问三个问题：基准是谁、成本算了吗、测了几次（E2）
    3. 超额收益不区分新钱旧钱，正交化和来源分解才区分——92% 被风格解释的"alpha"不是 alpha（E3/E5/E10）
    4. 预注册在触碰数据之前完成；规则改动=实验重做（E4）
    5. OOS 是消耗品：一次性判定、假设族封禁、变体禁令，全部指向同一原则（E4/E6/E10）
    6. 越符合预期的数字越优先审计——错得好代价大（E7）
    7. 修数据是最后手段：约定改用法、artifact 做隔离、认知错改文档（E9）
    8. 结论依赖差分还是水平，决定它对数据偏差的免疫等级（E8）
    9. 监控也会坏，且坏了照常输出确定性——元监控与人工抽检是必需（E11）
    10. 把"不研究什么"写得和"研究什么"一样正式（E12）

    4. 战役矩阵终局与"负结果的复利"¶

    真实战役走到课程成稿时的全景（简化）：

    战役 结局 遗产
    A 股 诚实口径零超额，DSR 全 FAIL excess_honest 口径、验证制度、假 alpha 的完整标本
    期货 r1 136 试验 postloop 全 FAIL 预注册验证管线本身、五坑中的三坑
    期货 r2 进行中（矩阵制） 六方向筛选、D-9 勘误、L2→观察线
    crypto r1 头名 +10.85% 不稳健，实为 baseline "排行榜头名≠真信号"的实证
    crypto r2 真信号=vol_20d/reversal_5d（教科书因子） 循环的合理预期：再发现经典，而非发明新颖
    funding carry SUPPORTED +2.37%/yr，影子中 唯一幸存者、监控预注册模板
    指数调样 INCONCLUSIVE，转前向轮 "等"也是判决
    业绩预告 REJECTED 判决执行三件套的模板

    注意"遗产"列的构成：几乎没有一条遗产是正收益策略，几乎全部是制度、口径、模板和标本。这不是安慰——这是这类研究组织真实的资产结构。策略会衰减，纪律会复利；一个产出了"验证制度 + 勘误能力 + 排除清单"的亏损战役，比一个靠未审口径赚了钱但不知道为什么的战役富有得多。后者的问题是：它的盈利无法归因，因此无法复制，也无法知道什么时候会消失。

    负结果的复利是这门课最想留下的观念：把每个 REJECTED 都记成一页可复算的档案，你的研究体系就在变大；把它们忘掉，你只是在反复支付同样的学费。

    5. 结课：AI 时代研究者的位置¶

    回到第一讲结尾那句话，现在可以给出它的完整版：

    AI 因子工厂替代的是"手"。而"判断"——数据可信吗、口径诚实吗、结果配得上选拔基数吗、这个方向值得花窗口吗——不仅没有被替代，它的稀缺性被放大了一百倍，因为假设的供给被放大了一百倍。

    这门课的全部内容，本质上是同一件事的十三个切面：在假设过剩的时代，研究者的核心技能从"产生好想法"迁移为"便宜地杀死坏想法"。工厂负责便宜地生产，你负责便宜地否决——体系的两端都是"便宜"，中间省下的，是不再为噪声支付真金白银的岁月。

    结课思考题（没有下一讲回收，请自己作答）：假设明天出现一个更强的模型，工厂的假设质量提升到研究员水准。本课程的哪几讲会过时，哪几讲不会？为什么？（一个思考方向：过时的会是关于"AI 能力边界"的描述性内容；不会过的是关于"验证与选择"的制度性内容——前者随技术贬值，后者随假设供给增值。）
