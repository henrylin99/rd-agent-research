# 番外一 · crypto 两轮战役：排行榜头名的三重人格

> 番外篇（不依赖主线顺序，但建议先读第二讲与第五讲）
> 学习目标：通过 crypto 两轮的完整故事，演示"同一个数字"在三种检验下的三副面孔。

## 1. 案例概述

crypto 战役跑了两轮。第一轮排行榜头名：**+10.85%**——一个足以让任何人心动的数字。最终结论：**不稳健，头名实为纯 baseline**。第二轮重启验证后确认的真信号：`vol_20d`（20 日波动率）与 `reversal_5d`（5 日反转）。

这个番外的价值在于：+10.85% 这个数字从头到尾没有变过，变的是**看它的镜头**。同一个数字在三重检验下呈现出三副面孔。

## 2. 第一副面孔：排行榜上的明星

孤立地看：+10.85%，策略逻辑自洽，回测曲线漂亮。这是它最危险的时刻——第五讲说过，人检查数字的默认逻辑是"离谱才查，合理放过"，而 10.85% 对 crypto 来说是个"克制得可信"的数字（比 100% 骗局低了两个数量级，比无聊的 2% 高了一个数量级）。数字合理性偏差（第七讲）的教科书案例。

## 3. 第二副面孔：技术鉴定下的 baseline

第一层拆解：**两个排行榜头部因子（9ebd7fdc / cfa700d4）经鉴定是纯 baseline**——代码审计发现它们的"因子逻辑"实际上是退化形式：等价于持有等权基准、或对全品种做无信息排序。它们的 +10.85% 不是 alpha，是**市场本身在那段时间的 beta**。

这一层的教学点在"怎么发现的"：不是靠统计（统计上看它很好），是靠**读代码**。因子实现层的审计是验证管线最容易被省略的一环——大家默认"跑出数字的代码就是它声称的代码"。LLM 生成的因子尤其需要这一关：第二讲讲过 versions 列有 33 个版本——**每多一个版本，"代码是否仍在做它声称的事"的举证责任就多一分**。

## 4. 第三副面孔：诚实口径下的幸存者

剥离假头名后重验：真信号只剩 `vol_20d` 和 `reversal_5d`。第三讲结论二在此得到最干净的实证：循环跑完两轮、上百个因子，活下来的两个都是**教科书因子**——波动率效应与短期反转是横截面研究里被验证了几十年的现象。

推论值得单独写一行：**AI 循环的合理预期是"高效率地再发现经典"，而不是"发明新颖"**。如果你雇一个研究助理，他干了一年，结论是"动量和反转在 crypto 也有效"——你会觉得这一年值吗？在假设成本近乎为零的新世界里，答案是值：他排除了其他一切，而排除本身就是产出（第五讲"负结果的复利"）。

## 5. 本番外小结

- +10.85% 的三副面孔：排行榜明星 → 代码审计下的 baseline → 剥离后的噪声
- 因子实现层审计（读代码）不可省略，统计检验覆盖不了"代码不做它声称的事"
- 循环挖掘的合理产出预期：再发现经典 + 排除其余

**思考题**：baseline 冒充因子在什么市场环境下最容易进排行榜头部？（提示：等权基准的高收益期——牛市。那么"排行榜头部集中在某段时间"本身可否作为审计线索？）
