# 第十讲 · funding carry：一个活下来的策略长什么样

> 第四章 · 活下来的策略长什么样（第一讲）
> 学习目标：以全课程唯一 SUPPORTED 的案例为标本，理解"通过验证"与"值得部署"之间的距离；掌握收益来源分解与量级预期管理。
> 前置：第二章（判定制度）、第七讲（carry 的期货版已死于双重复权）。

## 1. 案例：crypto 永续资金费率 carry

**策略**：crypto 永续合约的资金费率（funding rate）机制下，费率为正时多头向空头付费、为负时空头向多头付费。策略做空高费率品种（收取资金费）、做多低/负费率品种——收益来自资金费率本身，价格腿近似对冲。

**判定**（预注册、OOS 一次性）：

> **SUPPORTed：OOS 年化 +2.37%，p < 0.0001。八项子检验（F1–F8）全部通过。**

这是两章验证制度运行以来，唯一一次全绿。但本讲的重点恰恰是：**全绿不等于故事结束**。判决书之后还有三问：钱从哪来、有多少、还能来多久。

## 2. 第一问：钱从哪来——收益来源分解

验证管线对策略收益做了来源分解：

> 资金费率贡献 = **109%**。

翻译：价格腿贡献为 **−9%**——策略在价格上小幅亏钱，全部净收益（甚至更多）来自资金费的计提。这个结构是**好消息**：资金费率是机制性现金流（协议规则强制支付），不是价格预测；价格腿为负说明对冲略有过头，但它把策略与价格方向脱钩了。

对照第五讲的教训（92% 收益被风格 beta 解释的"伪 alpha"），这里的 109% 是**合格的收益结构**：来源明确、机制可解释、与已知 risk premium 的关系清晰（carry 类收益，与商品 carry、货币 carry 同族）。正交化对手检验在这里的意义是确认"它赚的不是动量/价值/低波的钱"——来源分解把这个问题回答得更彻底。

但注意一个更深的问题随之浮出：**如果收益 109% 来自资金费，这个策略本质上不是"预测策略"，而是"收费策略"**。它不预测任何价格，它只是站在资金费支付流的收款侧。这决定了它的一切后续属性——量级、风险、监控重点——都与预测型策略完全不同。

## 3. 第二问：有多少——量级与"现金管理级"的定位

年化 2.37%。第七讲那个假的 carry 号称 18% 时，几乎骗过所有人；这个真的 carry 只有 2.37%——课程第三次回到同一条规律：

> **真 alpha 又小又难看；假 alpha 又大又合理。**

对 2.37% 的正确处理不是失望，而是**重新归类**：这个量级不属"策略收益"，属"现金管理增强"——它对标的是闲置保证金的利息收入，而不是主策略的收益目标。实际定位决策也是这样做的：作为组合的卫星收益流，占用小部分资金，不承担主攻角色。

量级预期的另一个维度：**波动性**。资金费率是 regime 化的——牛市狂热期费率高企（策略丰收），平静期费率贴地（策略接近零收益）。2.37% 是样本期的平均，它不是每月均匀到账的年金，而是跟着市场情绪的丰歉年。这个特性直接决定了下一讲影子监控要盯什么。

## 4. 第三问：还能来多久——衰减监控的预先设计

收费策略的终极风险是**收费理由消失**：资金费率机制改变、或市场参与者把高费率品种的价格打到均衡（套利拥挤）。为此，判决的同时预注册了监控方案，而不是等出事再想：

- **收益构成持续分解**：资金费贡献占比是第一监控指标——它从 109% 开始下滑（价格腿开始主导）即预警机制衰减
- **费率 regime 跟踪**：截面费率水平的历史分位，判断当前是丰是歉，而非把平静期误判为"策略失效"
- **变体禁令**：判决时同时生效——禁止围绕它衍生新变体（换品种池、加杠杆、改对冲比例）再次申请验证。理由与第六讲的假设族封禁同构：**变体是对同一 OOS 数据的变相复测**，每衍生一个变体，原始判决的统计效力就被稀释一分

变体禁令值得多说一句，因为它反直觉：策略验证通过了，为什么不让它"进化"？因为进化方向的选择会被同一个数据集的印象引导——你总觉得"如果把那两个品种换掉会更好"，这个感觉本身就来自对样本内表现的记忆。沿着它衍生变体，等于用样本内直觉反复透支同一段 OOS。真要进化，走前向：新数据、新预注册。

## 5. 一个策略的完整档案

把 funding carry 的完整档案摊开，作为"活下来的策略"的标准模板：

| 维度 | 内容 |
|---|---|
| 假设 | 机制性（资金费支付流），非预测型 |
| 判决 | 预注册 OOS 一次性：SUPPORTED（+2.37%/yr，p<0.0001，F1–F8 全过） |
| 收益结构 | 资金费贡献 109%，价格腿 −9%，与价格方向脱钩 |
| 定位 | 现金管理级卫星收益流，非主策略 |
| 风险画像 | 费率 regime 化（丰歉年）；机制变更风险；拥挤风险 |
| 监控预注册 | 资金费贡献占比 + 费率分位；衰减触发条件先写好 |
| 变体禁令 | 生效；进化只走前向新预注册 |
| 下一步 | 影子监控 30 天（下一讲） |

对照第五讲那 290 个因子的待遇——它们没有一个走到这张表的第二行。**验证通过不是终点，是获得"被认真对待资格"的起点。**

## 6. 本讲小结

- 收益来源分解（109% 资金费）是比正交化更彻底的"新钱还是旧钱"检验；收费型策略与预测型策略需要完全不同的风险框架
- 年化 2.37% 的正确定位是现金管理级——量级预期管理是验证制度的延伸
- 衰减监控在判决时预注册：盯收益构成，不盯净值
- 变体禁令：验证通过后的衍生改进是对 OOS 的变相复测，进化只走前向

**思考题**：若未来某季度资金费贡献占比降到 60%（价格腿贡献转正），策略净值不变。按本讲的监控逻辑，这是好消息还是坏消息？（提示：价格腿贡献上升意味着策略正在从"收费"漂移向"预测价格"——它的风险来源变了，而当初的 SUPPORTED 判决并没有覆盖这种形态。）
