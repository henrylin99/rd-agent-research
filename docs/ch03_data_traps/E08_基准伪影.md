# 第八讲 · 基准伪影：当"超额"这个量本身是错的

> 第三章 · 数据口径的暗雷（第二讲）
> 学习目标：理解基准口径如何系统性制造虚假超额；掌握分红处理错误对总收益的污染；建立"审计要向下问到量的定义层"的习惯。
> 前置：第五讲（基准伪影首次提及处）。

## 1. 案例概述

A 股战役的独立验证期间发现：排行榜口径所用的基准构造中，**涨停股被剔除在外**。这一个看似无害的细节，导致"超额收益"这个量本身被系统性污染。换成诚实口径重算后：

> **双周调仓 top200 组合相对基准的"超额"完全消失。此前的超额中相当部分是基准定义制造的伪影。**

第五讲说过这是四层审计栈最底下的一刀——因子验证做得再严格，基准错了，全部结论的地基就错了。本讲把这一刀完整展开。

## 2. 机制：剔涨停如何变成"超额"

逐步拆解这个魔术：

**第一步：基准里没有涨停股。** 基准组合在构建时剔除当日涨停的股票（可能出于"可交易性"考虑——涨停买不进）。

**第二步：策略组合里有。** 因子选股逻辑不知道也不关心基准剔了谁——动量强的票、涨停过的票照选。

**第三步：A 股涨停有次日惯性。** 涨停（尤其非一字板）的股票次日平均有正漂移，这是市场微观结构决定的（封板资金、情绪延续、涨跌停制度下的排队效应）。

**第四步：伪影成型。** 策略组合持有一篮子"含次日正漂移成分"的票，基准剔掉了这部分——**策略什么都没做对，只是站在了基准剔除规则的对立面**。选出的票越倾向涨停，"超额"越好看。动量类因子（排行榜大户，第二讲见过 33 个版本的 momentum_20d）在涨停剔除的基准面前天然占优——它们的"alpha"有相当一块是这条基准规则送的。

注意这个伪影的毒性：它**不可套利**。你按这个策略实盘，涨停的票你同样买不进（或买在次日高开）；回测里的"超额"对应的是现实中拿不到的成交。它和第七讲的 bug 又是不同的失效模式——数据没错、代码没错、统计没错，**量的定义就注定产生误导**。

## 3. 基准设计的隐性自由度

这个案例揭出一个常被忽视的真相：**基准是一个自由度极高的研究决策**，但它极少被当作研究决策来对待。同一段历史、同一个策略，基准可选：

- 全市场等权 / 剔除涨停 / 剔除 ST / 剔除停牌
- 沪深 300 / 中证 500 / 中证 1000
- 市值加权 / 等权

每一条都合法、都有理由，而组合起来的空间足以把任何一个平庸策略"调"出显著超额。研究者很少故意作弊——更常见的路径是：试了几种基准，无意识地记住了结果好看的那种。这正是第四讲"研究者自由度"在**量的定义层**的重现——比参数层的自由度更隐蔽，因为它藏在"口径"名义下，从不进入稳健性检验的清单。

制度性对策与因子验证同构：**基准口径进预注册**。战役的实际处置是新建 `excess_honest`（诚实口径超额）作为全部后续汇报的唯一口径，旧口径的数字全部重算。命名本身就是纪律——让"诚实"成为显式属性而非默认假设。

## 4. 同一层的另一颗雷：分红双重扣减

A 股面板的第二个口径缺陷（同期发现）：构建收益序列时，**除权日的分红被扣减了两次**——总收益被系统性低估。

修正公式干净利落：

> 真实总收益 = (1 + 面板收益) / (f_ratio)²

（f_ratio 为除权因子；除以 f_ratio² 恰好抵消双重扣减。）修正后与 tushare 独立数据零误差对齐。

这个案例的教学价值在它的**结论结构**：

- **相对量结论幸存**：因子之间的相对排名、多空价差的符号，在整体低估下大体不变——因为偏差近乎等比例地作用于两侧
- **绝对量结论全部失真**：任何"年化 X%"式的绝对水平陈述都作废

推广成一条审计原则：**数据偏差对结论的杀伤力，取决于结论依赖的是差分还是水平**。依赖差分（排名、价差、相对强弱）的结论对同向偏差稳健；依赖水平（收益率、波动率、Sharpe 的分母）的结论一损俱损。检查你的关键结论依赖哪种，就知道了该为数据口径花多少审计预算。

## 5. 审计栈的补全：第五层

第五讲的四层审计栈到此可以补上地基之下的最后一层：

```
第 5 层  量的定义     基准构成 / 超额的定义 / 可比性     —— 这个量在度量你以为的东西吗
第 4 层  统计充分性   DSR / 多重检验校正
第 3 层  收益来源     正交化 / 归因分解
第 2 层  可实现性     换手 × 成本敏感性
第 1 层  数据地基     复权 / 日期戳 / 拼接               —— 第七讲、第九讲
```

第五层是最少被审计的一层，因为它出问题时**不报错**：代码正常运行，数字正常产出，图表正常好看。剔涨停的基准跑了整个战役才在一次交叉对账中暴露；分红双重扣减靠的是"独立数据源零误差对齐"这种强校验才抓到。

两条通用对策（战役实证有效）：

1. **独立源对齐校验**：面板收益与至少一个独立数据源做逐点对齐，误差应精确为零——任何非零都指向口径差异，值得追查
2. **口径清单化**：基准的每条构成规则、复权方法、剔除逻辑列成显式清单进预注册文档。写不出来的口径（"就是默认那个"）就是最大的风险敞口

## 6. 本讲小结

- 基准剔涨停 + 策略持涨停股 + 涨停次日惯性 = 无需任何 alpha 的"超额"；且该超额实盘不可得（买不进涨停票）
- 基准是高自由度研究决策，必须进预注册；"诚实口径"应当显式命名、成为唯一汇报口径
- 分红双重扣减：相对量结论幸存、绝对量结论失真——按结论依赖差分还是水平分配审计预算
- 审计栈第五层（量的定义）出问题不报错，靠独立源对齐和口径清单化兜底

**思考题**：一个多空对冲策略（多头 top 组 + 空头 bottom 组，二者同池选股）对基准伪影的暴露度，与一个纯多头指数增强策略相比，谁高？为什么？（提示：多空的"基准"是池本身；纯多头的基准是外部指数——伪影需要通过哪条路径进入收益？）
